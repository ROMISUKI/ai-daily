**网站：<https://romisuki.github.io/ai-daily/>**

- 最新一期、按日期归档、主题筛选和本期关键词搜索。
- 三分区导航、实现链路/复现思路、需求证据/低成本验证、成本与风险；取消整份日报最多10条的限制。

- B站、X与YouTube原始来源链接和每条证据覆盖说明；只引用公开内容，不复制账号数据或全文字幕。
- 手机适配、RSS订阅，无外部字体或第三方统计脚本。
- 纯静态网站，不需要服务器、数据库或模型调用。

## 发布边界

本仓库只包含网站模板、生成/校验脚本和经过字段白名单处理的公开编辑内容。**不包含**账号登录态、密钥、浏览器配置、采集日志、原视频、全文字幕或完整抓取结果。日报原始采集与模型生成在独立的本地环境进行，不在GitHub Actions中登录来源网站或调用模型。

发布内容必须满足精确24小时时间校验、编辑结构与引用校验。v2可以发布明确标记缺项、但已有编辑结果通过校验的一期；没有通过汇总校验的原始候选和模型降级线索不得发布。不会用旧内容伪装当天更新，网页日期表示真实一期。

GitHub链接只能来自相应来源中提及、且已核验可公开访问的仓库；必须说明与案例的关系，不拿底层参考或同类软件冒充作者完整实现。页面核验不等于执行程序或全面代码审计。

内容结构、检索方向和运行边界见 [编辑方案](EDITORIAL_DESIGN.md)。本仓库公开的是网站/生成与校验源码；登录采集和定时编辑脚本仍在独立本机环境，不把账号环境一并推送。

## 本地构建

要求Node.js 20及以上，无第三方运行依赖。

```sh
node --test scripts/site.test.mjs
node scripts/build.mjs --reports-dir ../private-local-reports
node scripts/validate.mjs
npm run preview
```

输入目录由维护者显式指定，不应放入仓库。生成器只提取编辑摘要、时间窗口、来源链接和证据范围，不复制原始文件。输出位于 `docs/`。

启用观测台时，首次构建还需传 `--codex-page <独立项目的public.html>`。后续未传此参数会保留已经审计的 `docs/codex/index.html`；本机日常发布器传入最新公开导出。只读取这个经过字段投影和短节选处理的文件，不复制独立项目、原始快照或日志。最初本地联调后，用户已明确授权将这次集成发布到GitHub。

预览服务器仅监听回环地址，保留项目站点路径前缀；默认地址会在终端输出。不要通过截图或测试数据泄露个人账号信息。

## GitHub Pages

发布分支为 `main`，目录为 `/docs`，启用HTTPS。`docs/.nojekyll` 表明这些文件已经预生成，不需要Jekyll处理。每日完成本地校验和推送后，由GitHub Pages部署。

网站使用相对路径，支持项目站点的 `/ai-daily/` 前缀。更换仓库名或域名时先修改 `site.config.json`，重新生成后验证链接和RSS。

提交身份使用仓库级GitHub noreply邮箱，避免公开私人邮箱；不改全局Git身份。推送不强制改写历史，网络中断后先查远程提交状态，再决定是否重试。

日常自动发布只提交校验后的 `docs/` 文件；模板、脚本等源码改动需要维护者另行审阅并提交。工作区存在未提交修改、远程出现其他提交或存在未经记录的本地提交时，自动发布停止并保留现场，不覆盖或强推。
