dsh 侧边栏浏览器自动化插件：用 Playwright 复用页面操作

B站作者大米菌666展示其开发的 dsh-browser-automation 插件：让智能体直接操作 dsh 侧边栏中的现有浏览器页面，复用登录态与标签页。口播称提供约12个工具，覆盖导航、填表、点击和快照确认，并可把跑通的流程保存为 Playwright 代码复用；较大快照会完整落盘，只把前部完整行交给模型。该视频为作者自述，未核验代码与实际稳定性。

为什么值得看

浏览器智能体常受截图坐标与登录态困扰；复用侧边栏现成页面和可复用脚本，可能降低重复操作成本，尤其适合本地 Web 应用测试与表单流程。

实现链路

作者称底层基于 playwright-cli，AI 通过工具对页面元素进行查找和操作，不依赖截图坐标；流程跑通后可生成并保存 Playwright 代码，下次直接执行。快照过长时完整原文落盘，模型只接收前部完整行。

最小复现思路

最小复现：在隔离测试环境用公开测试页验证导航、填表、点击和快照，记录失败重试与登录态复用情况，再决定是否接入真实业务。

已知与推测

来源披露：B站简介与AI字幕自述；实现细节、效果与稳定性均未独立核验。

成本与风险

需 npm 包、Playwright 运行环境、dsh 插件机制及浏览器权限；涉及登录态和页面数据，需隔离凭据、最小权限与审计；页面改版、选择器失效和平台风控会影响稳定性。

边界与疑点
