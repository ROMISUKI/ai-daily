Gemini 3.8 Flash TTS 新增语音设计与声音复刻

Google for Developers 发布视频，介绍 Gemini 3.8 Flash TTS 与 Flash-Lite TTS 支持语音设计与声音复刻：用户可在 AI Studio 用文本描述年龄、性别、口音、语言等生成自定义音色，也可复刻自己的声音，并通过 Gemini API 以 voice ID 调用。官方称支持100多种语言。该更新把音色设计与 API 调用串起来，利于多语言语音应用，但视频为官方演示，未提供独立评测、延迟、价格或滥用防护细节。

为什么值得看

实现链路

官方演示链路：在 ai.studio/generate-speech 选择 voice design 或 voice replication，用文本提示描述音色或复刻声音，生成 voice ID，再经 Gemini API 调用。支持100多种语言为官方说法。

最小复现思路

最小验证可固定同一段多语言文本，分别测试文本描述设计音色与经授权的声音复刻，记录音质、延迟、口音稳定性及 API 返回；先确认配额与商用条款。

成本与风险

边界与疑点
