      i 如何认定重置+

      本人原帖优先

      直接读取 @thsottiaux 的近期主帖与本人回复，补充回复优先于主帖的含糊短句。明确说明“已完成、已传播、额度已重置”才算本人完成声明；只有“重置日”“will / landing / tomorrow”只算预告。短句“Done”必须关联已核实的重置会话。

      原帖 ≠ 个人到账

      本人完成声明不等于你的账户已经到账。重置卡、局部补偿、全局额度重置分开记录；本页不连接个人账号。未来时间到点、第三方观测或概率，都不会自动变成本人完成确认。

      历史与观测单独标记

      旧历史档案仍保留第三方分类，未逐条重新核验。第三方observed记录可能仅依据预告时间，单独展示，不用于常规完成计时及间隔统计。历史四分位窗口不是官方排期或概率。

      每小时核查，有变化才发布

      本机开机登录时每小时检查X，有内容或状态变化才更新公开快照，不为每次无变化检查提交Git。网页只显示已发布快照；刷新按钮重载网页，不调用个人账号或绕过CORS抓X。临时断网至少等5分钟，最多额外3次；失败保留旧证据并标明读取限制。日报仍每天05:00。
