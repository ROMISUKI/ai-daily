实现链路

最小复现思路

已知与推测

来源披露：官方原帖及已核验公开仓库README明确了检查入口、状态码、测试方式和限制；本条未运行代码、审计实现或对任何真实网站执行扫描。

成本与风险

公开页面核验不等于运行或安全审计。工具不跟随重定向、不检查响应体，也不独立确认修复是否已回移；仓库关于稳定补丁包含修复的假设仍需与官方发布记录核对。
