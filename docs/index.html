开发工具与智能体

DeepInfer开源：DeepSeek公开V4.1-Flash离线推理框架

DeepSeek官方开源内部大规模推理框架DeepInfer（Apache 2.0），用于离线运行DeepSeek-V4.1-Flash。仓库提供FlashMLA、DeepGEMM、DeepEP等优化内核，以及注意力DP/CP、MoE EP+EPLB、DSpark草稿验证、异步批调度、批不变推理、确定性采样和结构化输出，支持NVIDIA SM100与昇腾950。

为什么值得看

开放对象从模型权重延伸到生产推理栈，开发者可研究批一致性和多类并行策略；但完整服务仍需自行补齐关键组件。

边界与疑点

当前仅含离线推理；完整服务所需KV cache、预填充/解码分离和副本负载均衡未包含，性能数据来自项目方，不能视为独立实测。

模型与研究

Claude设计蝎毒结合蛋白：211项实验有17项达标

Anthropic称，其内部研究模型在64小时内调用12种设计工具生成318,484个候选，筛出180个并补至211个，交由Adaptyv Bio与Twist Bioscience用表面等离子共振测试。17个设计在两实验室达到“各重复有信号且KD不高于1 µM”的结合标准，其中两项对Cn2为个位数纳摩尔。

为什么值得看

案例把模型输出送入合作实验室验证，说明AI蛋白设计可进入湿实验迭代；同时，多毒素目标未成功，也暴露从高亲和结合到通用药物的难度。

边界与疑点

候选页面正文未完整采集；官方明确未验证细胞环境中的中和能力，不能称为抗毒药；多毒素设计无一达标，结果亦受提示与工具链限制。

Flora开放权重，规模化生成机器人训练信号

机器人研究者Jim Fan宣布开放Flora模型权重，用于从第一视角与机器人视频生成带时间戳字幕、稠密进度奖励及真实世界评测量规，为训练数据筛选、质量控制和强化学习后训练提供信号。其数据引擎据称在500张GPU上每天标注20万小时视频，并称成本较Astra低125倍。

边界与疑点

Vercel推出durable harness，让编码智能体跨故障续跑

Vercel发布名为durable harness的持久化代理运行方案，面向Pi、OpenCode、Codex、Claude Code、eve、fx以及自建harness。其核心机制是在任务失败后自动恢复，并让代理连续运行数小时、数天乃至数月，为长时间编码与自动化任务提供可续跑的执行载体。

为什么值得看

代理系统的瓶颈正从单次回答转向长任务的可靠执行；故障自动续跑使数小时级工作流具备更接近生产服务的运维语义。

边界与疑点

官方短帖未披露持久化实现、隔离机制、配额、价格或可用范围；“持续数月”是功能描述，不是长期稳定性实测。

机器人与硬件

微软与联发科展示MicroLED可插拔光互连

Microsoft Research称，联发科在OCP全球峰会演示了采用微软研究技术的MicroLED光链路：以LED替代铜互连或激光，在标准可插拔形态中并行传输多路数据。官方将其定位为面向AI数据中心、提升互连可靠性并降低功耗的下一步，重点是解决高密度数据传输而非增加计算吞吐。

为什么值得看

AI集群扩展会把供电、散热与互连推到同等关键位置；若MicroLED能实现可靠且低成本的并行链路，可能改变数据中心内部的连接方式。

边界与疑点

证据来自微软官方短帖对“上周”演示的转述；未给带宽、距离、误码率、功耗、成本或耐久性数据，也不是本窗口内的新实测。

Eleven Realtime主打约半秒起话的语音到语音模型
